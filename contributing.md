<summary><b>What is a deauthentication attack?</b></summary>
A deauth attack forcibly disconnects a device from a WiFi network by sending fake deauthentication frames. It's used in legitimate security testing to assess network resilience.
</details>

<details>
<summary><b>Do I need special hardware?</b></summary>
Yes — you need a WiFi adapter that supports monitor mode and packet injection (e.g., Alfa AWUS036ACH, TP-Link TL-WN722N v1).

Use WPA3, enable management frame protection (802.11w), use client isolation, and monitor for unusual disconnections.
